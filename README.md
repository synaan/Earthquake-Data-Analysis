🌍 Earthquake Data Analysis (EDA)
📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an earthquake dataset to understand patterns in seismic activity. The analysis focuses on factors such as magnitude, depth, and geographical location to identify trends and high-risk regions.

The goal of this project is to gain insights into earthquake occurrences and understand the relationships between different seismic parameters.

📊 Objectives

Analyze earthquake magnitude, depth, and location patterns

Identify trends and distribution of earthquakes

Discover relationships between seismic variables

Visualize earthquake data using charts and graphs

🛠 Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Jupyter Notebook

📂 Dataset

Source: Kaggle

The dataset contains information about earthquake occurrences including magnitude, depth, time, and location.

Data cleaning and preprocessing

Statistical summary of earthquake data

Visualized seismic activity trends across different regions
